# 班级每日作业展示板

给班级一体机 / 教室大屏用的「今日作业」看板。**单文件 HTML、零依赖、零构建、断网可用** —— 双击 `index.html` 就能跑，六科作业以 3×2 大卡片铺满整屏，3 米外清晰可读。

## 快速开始

1. 拿到文件：`git clone https://github.com/Yexiao-bbj/homework-board.git`，或直接下载 ZIP 解压。
2. 双击 `index.html`，用 Chrome / Edge 打开；按 `F11` 全屏即可作为大屏展示。
3. Windows 上可双击 `setup-shortcut.bat`，在桌面生成带图标的「班级每日作业展示板」快捷方式。

> 不需要 Node.js、不需要 `npm install`、不需要起服务，也不需要联网。整个目录也可以直接放到任意静态服务器上。

## 功能

- **六科大卡片**：语文 / 数学 / 英语 / 物理 / 化学 / 生物，每科独立配色，正文 36px 起，内容放不下时自动缩到最小 28px，保证整段文字完整可见；也可关闭自适应，用 `−` / `+` 手动调节。
- **展示态 / 编辑态双态**：默认只读防误触；`F2` 进入编辑，输入框失焦即自动保存，点「保存并退出」或按 `Esc` 收工。卡片角标实时显示「已布置 / 无作业 / 未保存 / 已保存」。
- **按日期存档**：`←` / `→` 翻看前后日期，「回到今天」一键归位；标题自动显示日期与星期，底部显示各科目更新时间。新的一天打开天然是空白页。
- **沿用昨天再改**：一键把前一天六科作业搬到今天（不覆盖已填内容），适合作业变化不大的日子。
- **备份与迁移**：编辑态可「导出 JSON」/「导入 JSON」。导入按「日期 + 科目」合并覆盖，其余记录保留，导入前有确认提示。
- **深浅主题**：一键切换浅色 / 深色，适配不同教室光照。
- **多标签页同步**：一个页面改了作业，其他展示态页面通过 `storage` 事件自动刷新，适合前门大屏 + 讲台电脑同时开着。
- **完全离线**：favicon 与标题栏图标均为内联 SVG，没有任何外部请求，内网 / 断网环境照常使用。
- **健壮性**：本地存储不可用时仍可录入展示，并提示立即导出备份；作业内容用纯文本渲染，不会执行 HTML/脚本。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `F2` | 进入编辑态 |
| `Esc` | 保存并退出编辑态 |
| `←` / `→` | 查看前一天 / 后一天（光标不在输入框时） |
| `Ctrl + Enter` | 在某一科输入框内立即保存该科 |

所有功能在屏幕底部按钮区也都有对应入口，触屏一体机不用键盘也能操作。

## 数据存储

数据保存在浏览器 `localStorage`，键名为 `classDailyHomework:v1:data`：

```json
{
  "2026-11-14": {
    "语文": { "text": "完成练习册 P32–33", "at": "2026-11-14 16:20" },
    "数学": { "text": "试卷订正", "at": "2026-11-14 16:25" }
  }
}
```

**请注意**：数据只属于「当前浏览器 + 当前打开方式」，换浏览器、换电脑、清理缓存都会丢失；请定期用「导出 JSON」备份。直接双击打开（`file://`）与通过 HTTP 打开属于不同来源，两边数据不互通，建议固定一种打开方式。导入时会校验日期格式与结构，非法数据会被跳过而不是污染原有记录。

## 目录结构

```
homework-board/
├─ index.html            # 全部 HTML / CSS / JS，单文件应用
├─ setup-shortcut.bat    # Windows：一键在桌面创建带图标的快捷方式
├─ homework-board.ico    # 快捷方式图标（仅 Windows 快捷方式用，页面不需要）
└─ README.md             # 本文件
```

`homework-board.ico` 是二进制图标文件，只用于桌面快捷方式；页面自身的图标已内联在 `index.html` 中，因此即使没有这个文件，展示板也完全正常使用。

## 想改点什么

- 换科目：修改 `index.html` 里的 `SUBJECTS` 数组，以及 `<main class="board">` 下对应的 `article.card`（`data-sub` 与标题保持一致）。
- 换配色：卡片 `style="--bar:#xxxxxx"` 与 `:root` 中的浅色 / 深色变量。
- 换字号范围：脚本中的 `applyFontToCard()`，默认 36px 起、按 2px 递减至 28px。
